# Unfair Flips - Archipelago Mod

## Thunderstore Install Guide (Recommended!)
1. Install [r2modman](https://thunderstore.io/package/ebkr/r2modman/) or something like it
2. Select Unfair Flips
3. Download the Archipelago mod on the online browser.
4. Click "Play Modded"
5. Enjoy!

## Manual Install Guide
1. Download [BepinEx](https://github.com/BepInEx/BepInEx/releases) 5.4 for x64 architecture
2. Extract all files into your Unfair Flips directory
3. Launch the game
4. Close the game
5. Download the [latest release of this mod](https://github.com/robotzurg/UnfairFlipsAPMod/releases)
6. Extract the UnfairFlipsAPMod folder into the bepinex/plugins folder in your game folder
7. Launch the game
8. Flip the coin
9. Land on tails
10. Cry

## How do randomize work?
Flip can only be heads if you have enough fairness.
Buy upgrades. Get as many heads in a row as you specified...
